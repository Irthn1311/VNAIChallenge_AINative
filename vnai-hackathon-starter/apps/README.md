# Apps

## Purpose

This folder will contain runnable applications in the implementation phase.

Current status: preparation only. No real app has been scaffolded yet.

## What belongs here

* `apps/web` - planned Next.js frontend.
* `apps/api` - planned FastAPI backend.
* App-specific README files.

## What does not belong here

* Shared packages used by multiple apps.
* Random experiments.
* Secrets or real environment files.

## Future examples

```text
apps/web/app/
apps/web/components/
apps/api/routes/
apps/api/services/
```

## Notes for AI coding

Do not scaffold Next.js or FastAPI unless the team explicitly starts implementation phase.
