# Preparation Roadmap

Roadmap này giúp team chuẩn bị trước khi code và trước hackathon thật.

---

## Phase 0: Documentation and workflow

Goal:

* Hoàn thiện docs nền tảng.
* Thống nhất tool stack.
* Thống nhất AI coding workflow.

Outputs:

* README.
* API contract planned.
* Team workflow.
* AI coding workflow.
* PR template.

---

## Phase 1: Team onboarding

Goal:

* Thành viên hiểu repo và cách nhận task.

Outputs:

* Mỗi người đọc onboarding guide.
* Mỗi người chọn vai trò chính/phụ.
* Ghi owner vào `MODULE_MAP.md`.

---

## Phase 2: Module contract practice

Goal:

* Mỗi người viết một module contract.

Outputs:

* Chat RAG contract.
* Upload Document contract.
* Frontend UI contract.
* Backend API contract.
* CV/OCR contract nếu cần.

---

## Phase 3: Mini tasks

Goal:

* Test workflow task nhỏ.

Outputs:

* 3-4 PR nhỏ.
* Review theo PR template.
* Cập nhật context pack nếu thiếu.

---

## Phase 4: Small AI-native mock project

Goal:

* Mô phỏng một sản phẩm AI nhỏ.

Outputs:

* Problem statement.
* Demo data.
* API contracts.
* Context packs.
* Optional scaffold nếu team đã chuyển phase.

---

## Phase 5: Mock hackathon

Goal:

* Chạy thử áp lực thời gian.

Outputs:

* Demo script.
* Pitch draft.
* Safety checklist.
* Retrospective về điểm mạnh/yếu của team.

---

## Phase 6: Template expansion

Goal:

* Mở rộng template nếu mock project cho thấy thiếu.

Outputs:

* More context packs.
* Better eval templates.
* Better prompt library.
* Deployment checklist nếu cần.

---

## Phase 7: Final preparation before event

Goal:

* Sẵn sàng bắt đầu coding khi có đề bài thật.

Outputs:

* Owners assigned.
* Tool accounts ready.
* Demo fallback habits clear.
* Decision docs updated.
* Team hiểu khi nào mới scaffold Next.js/FastAPI.
