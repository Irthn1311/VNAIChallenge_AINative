# Samples

## Purpose

Store stable sample data for demo and local testing.

## What belongs here

* Sample documents.
* Sample images.
* Sample CSV files.
* Sample questions and expected outputs.

## What does not belong here

* Private user data.
* Real confidential documents.
* Large files that slow the repo.
* Random untested data.

## Future examples

```text
documents/
images/
sample_questions.md
sample_outputs.md
```

## Notes for AI coding

Demo data should be boring, stable, and easy to explain. Prefer small files that always work.
