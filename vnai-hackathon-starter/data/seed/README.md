# Seed

## Purpose

Store future seed data for resetting a demo database.

## What belongs here

* Small demo seed files.
* SQL seed scripts if needed.
* CSV/JSON fixtures for local demo reset.

## What does not belong here

* Production data.
* Secrets.
* Huge dumps.
* Destructive reset scripts without warning.

## Future examples

```text
seed.sql
demo_users.json
customers.csv
orders.csv
```

## Notes for AI coding

Seed data should be easy to reset and safe to share in the repo.
