# Eval

## Purpose

Store evaluation questions and expected behavior for AI/RAG/CV demo checks.

## What belongs here

* RAG evaluation questions.
* Hallucination checks.
* Demo test cases.
* Expected output notes.

## What does not belong here

* Private data.
* Metrics claims without evidence.
* Random prompts not tied to a module.

## Future examples

```text
rag_eval_questions.md
demo_test_cases.md
hallucination_checks.md
cv_ocr_eval.md
```

## Notes for AI coding

Use eval files to test whether AI answers are grounded and whether unsupported questions are handled safely.
