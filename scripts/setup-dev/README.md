# Setup Dev

## Purpose

Future setup scripts for local development.

Current status: no setup script is active because app code has not been scaffolded yet.

## What belongs here

* Environment setup scripts.
* Local dependency setup notes.
* Developer machine checklist.

## What does not belong here

* Real secrets.
* Commands that install packages before the team approves implementation phase.
* Destructive machine changes.

## Future examples

```text
install-web.ps1
install-api.ps1
setup-env.ps1
```

## Notes for AI coding

Scripts should be safe, documented, and easy to run on Windows PowerShell.
