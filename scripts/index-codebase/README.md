# Index Codebase

## Purpose

Future notes or scripts for using GitNexus, CodeGraph, and Repomix to understand the repo.

## What belongs here

* Repomix command notes.
* CodeGraph setup notes.
* GitNexus onboarding notes.
* Safe context packaging instructions.

## What does not belong here

* Secrets.
* Full private data exports.
* Generated context dumps that are too large to review.

## Future examples

```text
repomix-commands.md
codegraph-setup.md
gitnexus-guide.md
```

## Notes for AI coding

Before sending context to external tools, check that no API keys or private files are included.
