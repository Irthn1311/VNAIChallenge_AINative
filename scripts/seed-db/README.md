# Seed DB

## Purpose

Future scripts for seeding or resetting demo database data.

## What belongs here

* Seed scripts.
* Reset scripts with clear warnings.
* Demo data import helpers.

## What does not belong here

* Production credentials.
* Dangerous reset commands without confirmation.
* Large private database dumps.

## Future examples

```text
seed-demo-data.py
reset-demo-db.py
import-sample-documents.py
```

## Notes for AI coding

Any destructive script must be clearly marked and should require confirmation.
